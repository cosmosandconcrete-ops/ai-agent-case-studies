# AI Agent Operations — Case Studies

Architecture and safety-design write-ups from production AI agent systems built and operated by Christian Rodriguez (Cosmos & Concrete Technical Solutions, San Antonio, TX). These are design case studies — no production code is included.

- **[Luna — AI Voice Receptionist](luna-voice-receptionist.md)** — a phone agent that books real appointments, built around approval gates, a no-invention rule, and calendar-as-source-of-truth.
- **[STARBREACH — Authorized Security-Testing Platform](starbreach-security-testing-platform.md)** — a validation-first security assessment platform: PTES/OWASP methodology, scope locks, kill switches, and approval-gated exploitation planning.
- **[Agent Fleet Operations](agent-fleet-operations.md)** — the shared operating patterns across an SMS booking assistant, lead follow-up, website chatbot, and monitoring system: draft-first approvals, outcome-verifying watchdogs, and script-vs-AI cost discipline.
